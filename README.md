# assinatura-emailzuffo

Imagem da assinatura de e-mail de Rogério da Silva Zuffo (Seazone), hospedada aqui para ser inserida no Gmail por URL.

## Arquivo

`assinatura_rogeriook.png`: cargo "Farmer de Parcerias Franquias".

## Link da imagem

```
https://raw.githubusercontent.com/rogeriosilva33-3/assinatura-emailzuffo/main/assinatura_rogeriook.png
```

O link só funciona enquanto o repositório for público e o arquivo estiver na `main`.

## Como usar no Gmail

1. Gmail → Configurações → Ver todas as configurações → Geral → Assinatura.
2. Criar nova assinatura → ícone de imagem → "Endereço da imagem (URL)".
3. Colar o link acima e salvar.
